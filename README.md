# Setup Steps for Staging Environment

1. Clone the repository:
   ```bash
   git clone https://github.com/niro2-1/add-staging-env-for-3.git
   cd add-staging-env-for-3
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Create a `.env` file in the root directory and add the necessary variables.

4. Start the staging server:
   ```bash
   npm run start:staging
   ```

5. Access the staging environment at `http://localhost:3000`.
